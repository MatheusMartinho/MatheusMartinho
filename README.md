## І. Sinopse

Desenvolvedor brasileiro. Autodidata por convicção, não por acidente.

Faço apps mobile do zero ao lançamento — 

Fora do código: **Bergman, Tarkovsky e Haneke** me ensinaram mais sobre
arquitetura de software do que qualquer bootcamp — economia, intenção, corte.
Xadrez para pensar. Astronomia para lembrar da escala. Fotografia de vida
selvagem para treinar paciência.
